# Changelog

## 0.1.0

First release.

- Rootform language mode for `.rf.hcl`: syntax highlighting, comments, bracket
  matching, automatic closing, indentation and folding.
- Diagnostics, completion, hover, go to definition and formatting from the
  local `rootform lsp`.
- **Rootform: Server Path** setting and **Rootform: Restart Language Server**
  command.
- The local executable starts only in trusted workspaces.
